# M02 — 屏幕定位

## 目标

根据工作区与卡片尺寸，计算右下角飞层 `Left`/`Top`（距任务栏安全边距可配置）。

## 产物

- `Core/Placement/FlyoutPlacementCalculator`
- `Core/Placement/PlacementRequest` / `PlacementResult`
- 单元测试覆盖多分辨率与边距

## 验收标准

- [ ] 给定工作区 `(0,0,1920,1040)`、卡片 `360×420`、边距 `16`，结果为右下角对齐（Left/Top 可断言）
- [ ] 工作区非原点、多显示器主屏场景有测试用例
- [ ] 相关测试全部通过
