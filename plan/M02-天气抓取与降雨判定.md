# M02-天气抓取与降雨判定

技术依据：见 `plan/技术方案.md`。

## 模块目标

完成和风天气逐小时数据抓取，并输出“今天/明天是否下雨、下雨时段、强度摘要”的标准结果。

## 实现范围

1. 封装和风 API 客户端（含超时、基础重试、错误分类）
2. 建立天气 DTO -> 领域模型映射
3. 实现降雨判定策略：`any_rain`（任意降雨信号即命中）
4. 输出两天摘要：
   - 今天：时段列表 + 强度汇总
   - 明天：时段列表 + 强度汇总

## 关键产物

- `HeWeatherClient`
- `RainDetectionService`
- `DailyRainSummary` 结构（日期、时段段落、强度标签）

## 验收标准

- API 正常时可得到今天/明天的判定结果
- 无雨时返回“无提醒”结果
- 单元测试覆盖：跨天边界、空数据、断续降雨时段合并
