# M03 — 飞层可见性状态机

## 目标

纯逻辑控制：托盘点击切换显示；指针离开卡片区域后延迟收起（防抖）。

## 产物

- `Core/Flyout/FlyoutVisibilityController`
- `Core/Flyout/FlyoutVisibilityState`

## 验收标准

- [ ] 初始为 `Hidden`
- [ ] `OnTrayClick`：`Hidden`→`Visible`，`Visible`→`Hidden`（切换）
- [ ] `OnPointerLeave`：仅在 `Visible` 时启动收起计时；计时内 `OnPointerEnter` 取消收起
- [ ] 收起延迟默认 300ms，可配置；超时后变为 `Hidden`
- [ ] 全部状态转换有单元测试
