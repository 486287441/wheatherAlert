# M05 — 托盘宿主与集成

## 目标

可运行宿主：托盘左键点击弹出/收起飞层；鼠标移出飞层自动收起；右键保留退出。

## 产物

- `src/WeatherAlert.TrayPopup.App`（WinExe + WPF + 托盘 STA）
- `App/TrayHostService`  wiring controller + window
- 集成测试：程序集加载、端到端状态机模拟

## 验收标准

- [ ] `dotnet run --project src/WeatherAlert.TrayPopup.App` 可启动（无 API Key 依赖）
- [ ] 左键托盘：飞层在屏幕右下角出现
- [ ] 再次左键或鼠标离开飞层（超过 M03 延迟）：飞层隐藏
- [ ] `dotnet test` 全绿；`verify-all-modules.ps1` 退出码 0
- [ ] 验收记录 M01–M05 均为通过
