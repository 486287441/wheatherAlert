# M05-稳定性与发布验收

技术依据：见 `plan/技术方案.md`。

## 模块目标

完成异常恢复、失败提醒节流、可发布构建与最终验收清单。

## 实现范围

1. 网络异常策略
   - 每轮最多 3 次指数退避重试
   - 连续失败仅发送一次错误提醒，避免刷屏
2. 通知文案统一
   - 仅输出“日期 + 时段 + 强度”，不输出建议语
3. 发布脚本与运行说明
   - `dotnet publish` 参数固化
   - 运行/回滚说明
4. 端到端验收
   - 有雨/无雨/跨天/切城/断网恢复场景

## 关键产物

- `RetryPolicyFactory`
- 发布脚本（PowerShell）
- `验收记录.md`（可选）

## 验收标准

- 连续网络失败不会重复弹错误通知
- 跨天后可再次提醒“今天有雨”
- 生成可运行发布包，冷启动与重启均正常
