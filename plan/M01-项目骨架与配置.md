# M01-项目骨架与配置

技术依据：见 `plan/技术方案.md`。

## 模块目标

建立可运行的 .NET 项目骨架、配置体系与基础日志，为后续天气抓取、通知和托盘模块提供统一入口。

## 实现范围

1. 创建 `src/WeatherAlert.App`、`src/WeatherAlert.Core`、`src/WeatherAlert.Infrastructure`
2. 建立依赖注入与配置加载（`appsettings.json`）
3. 接入结构化日志（文件滚动）
4. 建立基础命令：立即检查触发入口（供托盘调用）

## 关键产物

- `Program.cs` 与 Host 启动流程
- 配置对象：API Key、默认城市、轮询间隔
- `IClock`、`IWeatherChecker` 等核心接口

## 验收标准

- `dotnet run` 能启动并保持后台运行
- 配置读取成功，缺失关键配置时有明确错误日志
- 手动触发检查命令可进入空实现流程（先打印日志）
