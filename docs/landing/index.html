01 · 功能

你需要的都在托盘里

  1. 降雨判定今明两日，按小时聚合。

    拉取和风 24 小时预报，根据降水量与降水概率判断今天、明天是否有雨，并合并连续降雨时段、标注强度。

  2. 托盘图标一眼分辨，不必点开。

    有雨显示雨伞，无雨显示铃铛。气泡提示可展示降雨时段摘要；API 异常时写入错误类历史记录，避免重复骚扰。

  3. 城市与定位自动识别，也可手选。

    支持 Windows 定位 + 和风 GeoAPI 解析城市；也可在完整中国城市列表中切换，默认北京（可在配置中修改）。

  4. 通知历史SQLite 持久化。

    每次降雨提醒与拉取失败均写入本地数据库，通过 WPF 历史窗口按时间浏览，数据存于 data/weather-alert.db。

  5. 后台轮询可配置间隔。

    默认每 60 分钟自动检查一次；托盘菜单可「立即检查」，命令行支持 --check-now 用于脚本或调试。

  6. 左键飞层毛玻璃快捷预览。

    左键点击托盘图标弹出飞层，快速查看当前城市与今明降雨摘要，无需打开完整窗口。

02 · 架构

分层清晰，便于维护

  1. 1 TrayPopup.App宿主：托盘 UI、后台 WeatherWorker、配置校验与 Serilog 日志。
  2. 2 TrayPopup.Core领域模型、降雨判定服务、仓储与 API 抽象接口。
  3. 3 TrayPopup.Infrastructure和风 API 客户端、SQLite 实现、重试与错误分类。
  4. 4 TrayPopup.Wpf历史记录、城市选择等 WPF 窗口与视图逻辑。
  5. 5 测试覆盖单元测试覆盖降雨判定、去重与核心业务路径，dotnet test 验收。
  6. 6 密钥不入库和风 API Key 通过本地 appsettings.Local.json 或环境变量配置，仓库仅保留占位符。

04 · 问答

常见问题

需要什么系统？
Windows 10 或 11。应用以系统托盘形式常驻，不占用任务栏主区域。
如何配置和风 API？
复制 appsettings.Local.json.example 为 appsettings.Local.json，填入 ApiKey 与专属 ApiBaseUrl；或设置环境变量 WEATHER_ALERT_Weather__ApiKey。请勿将真实 Key 提交到 Git。
怎样判断「有雨」？
对今明两天的逐小时预报，若降水量大于 0 或降水概率大于 0，即视为有雨信号，并合并相邻时段、给出强度标签。
托盘左键和右键分别做什么？
右键：立即检查、历史记录、切换城市、退出。左键：打开毛玻璃飞层，快速预览今明降雨摘要。
日志和数据存在哪？
日志在 logs/，数据库在 data/weather-alert.db，二者均在 .gitignore 中，不会进入版本库。

更多细节见项目 README 与 plan/ 目录下的模块说明。
