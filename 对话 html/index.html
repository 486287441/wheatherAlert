一、已定（来自粗糙需求，无需选择）

  • 软件在 Windows 后台常驻运行，每小时自动获取未来 24-48 小时逐小时天气。
  • 重点检测“今天是否下雨”和“明天是否下雨”。
  • 任一目标日期出现降雨时，用 Windows 原生 Toast + 官方通知音提醒。
  • 同一天降雨提醒只通知一次，避免重复骚扰。
  • 程序需要本地持久化通知状态，重启后可恢复。
  • 总体目标是“轻量、低打扰、可靠”。
