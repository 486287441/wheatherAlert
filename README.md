# wheatherAlert

Local weather alert helper project.

## Quick Start

1. Run `start-weatheralert.bat` to start.
2. Run `stop-weatheralert.bat` to stop.
3. Use `enable-autostart.bat` / `disable-autostart.bat` to manage startup behavior.

## Notes

- Sensitive values (API keys, tokens, local secrets) should be stored in environment files and are ignored by `.gitignore`.
- Do not commit production credentials into this repository.
